# Para Ganar Dinero — producto digital de entrega directa

## Producto elegido
**Control de Ventas para Emprendedores** — documento editable para registrar ventas, pedidos, cobros pendientes y gastos.

- Precio de lanzamiento propuesto: **ARS $1.000 por copia**.
- Público: emprendedores y pequeños comercios de San Patricio del Chañar.
- Intercambio: confirmar el pago y enviar manualmente el archivo por WhatsApp.
- Sin cuentas, suscripciones, backend ni infraestructura paga.

## Archivos
- `index.html`: calculadora gratuita Precio Claro (herramienta existente).
- `kit-emprendedor.html`: página de presentación y pedido del producto.
- El archivo completo que se entrega al comprador debe mantenerse fuera del repositorio público y enviarse manualmente después de confirmar el pago. No subir el archivo vendido a un repositorio público: cualquier persona podría descargarlo gratis.

## Antes de publicar la venta
1. Confirmar que GitHub Pages esté habilitado para la rama principal.
2. Configurar el número de WhatsApp del vendedor en el botón de contacto para que abra el chat correcto.
3. Probar la página desde un teléfono.
4. Entregar el documento solo después de confirmar el pago.

La página de presentación no procesa pagos ni verifica transferencias. El cobro y la entrega son manuales. No se prometen ventas ni resultados económicos.
